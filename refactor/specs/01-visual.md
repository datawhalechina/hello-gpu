# 01 视觉规范

> 适用范围：新版站点的所有页面和组件。参考稿在 `refactor/design/*.dc.html`（设计画布源码，可直接复制其中的 SVG 和配色），线上画布：https://claude.ai/artifact/2BCFWVsXQf26XDc6Z1C85q （仅作者可见）。

## 1. 风格定位

**精致科技风 + 一个有亲和力的吉祥物。** 冷白底、点阵网格、细描边、柔和阴影、等宽字体标签、电光青强调色。可爱只留给吉祥物「小核」和线程小机器人，界面本身保持克制、专业。

- 要：留白充足、层级清楚、数字和标签用等宽字体、一屏只有一个强调色焦点。
- 不要：粗黑描边贴纸风、大面积渐变铺底、emoji、彩虹配色、阴影堆叠、左侧色条卡片。

## 2. 设计 token

所有颜色、圆角、阴影都通过 CSS 变量使用，组件里不写死十六进制值。token 定义在一个文件里（任务 F-01 落地），亮色和暗色各一套。

### 2.1 中性色与表面

| token | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| `--hg-bg` | `#F5F7FB` | `#0B1220` | 页面底色 |
| `--hg-dot` | `#D5DCE8` | `#1E293B` | 点阵网格的点（1px，间距 22px） |
| `--hg-surface` | `#FFFFFF` | `#111A2E` | 卡片 |
| `--hg-surface-2` | `#F8FAFC` | `#0F172A` | 卡片内的次级区域、分段控件底 |
| `--hg-border` | `#E2E8F0` | `#253049` | 1px 描边 |
| `--hg-border-strong` | `#CBD5E1` | `#334155` | 输入框、次级按钮描边 |
| `--hg-ink` | `#0F172A` | `#E2E8F0` | 正文、标题 |
| `--hg-ink-2` | `#475569` | `#AAB4CF` | 次要文字 |
| `--hg-ink-3` | `#64748B` | `#8391B3` | 说明、标签 |

### 2.2 语义色（全站固定含义，任何区域都不改含义）

| token | 亮色（填充 / 文字） | 暗色（填充 / 文字） | 含义 |
| --- | --- | --- | --- |
| `--hg-accent` / `--hg-accent-ink` | `#14B8A6` / `#0F766E` | `#2DD4BF` / `#5EEAD4` | 进度、完成、可操作的焦点 |
| `--hg-accent-soft` | `#F0FDFA` | `rgba(45,212,191,.12)` | 强调区域底色 |
| `--hg-violet` / `--hg-violet-ink` | `#8B5CF6` / `#6D28D9` | `#A78BFA` / `#C4B5FD` | 先猜、新术语、概念 |
| `--hg-sky-ink` | `#0369A1` | `#7DD3FC` | 动手实验（LAB）标签 |
| `--hg-amber` / `--hg-amber-ink` | `#F59E0B` / `#B45309` | `#FBBF24` / `#FCD34D` | 星星、警告、重复计算 |
| `--hg-error` / `--hg-error-ink` | `#DC2626` / `#B91C1C` | `#F87171` / `#FCA5A5` | 越界、错误 |
| `--hg-error-soft` | `#FEF2F2` | `rgba(248,113,113,.14)` | 错误区域底色 |

主按钮用 `--hg-ink` 深色底配白字（暗色主题反过来），不用强调色。强调色只表达「进度 / 完成 / 焦点」。

### 2.3 线程块分类色

只用来区分「第几组」，不表达对错：`#38BDF8` `#2DD4BF` `#A78BFA` `#FB923C` `#F472B6` `#A3E635`，对应浅底 `#E0F2FE` `#CCFBF1` `#EDE9FE` `#FFEDD5` `#FCE7F3` `#ECFCCB`。超过 6 组循环使用。

### 2.4 代码区

深色代码区在亮暗主题下都使用：底 `#0B1220`，文字 `#E2E8F0`，行号 `#475569`，关键字 `#C4B5FD`，当前重点行 / 读者要改的表达式 `#FCD34D`，边界检查等「安全」代码 `#5EEAD4`。代码区顶部有一条文件名栏（等宽 12px，`#94A3B8`）。

### 2.5 形状与阴影

- 圆角：卡片 16–20px，控件 10–12px，标签和小块 6–8px，药丸 999px。
- 描边：一律 1px（输入框和次级按钮 1px `--hg-border-strong`）；插画线条除外。
- 阴影：`0 1px 2px rgba(15,23,42,.05), 0 8px 24px rgba(15,23,42,.06)`；深色英雄区可用 `0 20px 48px rgba(15,23,42,.18)`。不叠加多层彩色阴影。
- 底纹：页面底色上叠 1px 点阵（`radial-gradient(var(--hg-dot) 1px, transparent 1px)`，22px）。代码区、深色英雄区和地图面板可用更暗的点阵。

## 3. 字体

- **不加载 Google Fonts**（国内无法稳定访问）。拉丁字体通过 `@fontsource` 包打进站点（自托管），中文用系统字体。
- 标题、数字：`Space Grotesk`（600/700），后接中文系统字体。
- 正文：`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。
- 等宽：`JetBrains Mono`（500/700），用于代码、数值、英文标签。
- 字号：新手村正文 16px、行高 1.65；手册正文 15px；h1 32–40px（字距 -0.01em）；卡片标题 17–19px。
- **眉标（eyebrow）**：等宽 12px、全大写、字距 0.08em，放在卡片左上角说明卡片类型：`MISSION`（青）、`PREDICT`（紫）、`LAB`（天蓝）、`NEW TERM`（紫）、`HINT`（琥珀）、`EVIDENCE`（灰）。

## 4. 区域换装

布局根元素带 `data-zone="novice|forge|trial"`，只改变外壳（底色、强调色、英雄区、地图块颜色、小核的配饰），**语义色不变**。

| 区域 | 底色 | 强调色 | 气质 | 小核配饰 |
| --- | --- | --- | --- | --- |
| novice 新手村 | 冷白 `#F5F7FB` | 电光青 `#14B8A6` | 圆角最大，反馈最活泼 | 默认款 |
| forge 铸造城 | 暖白 `#FFFBF5` | 铜橙 `#F97316`（文字 `#C2410C`） | 精密工坊，动效收敛 | 黄色安全帽 |
| trial 试炼场 | 深紫 `#15132A` | 霓虹青 `#22D3EE` + 紫 `#8B5CF6` | 描边更细，几乎不弹跳 | 青色护目镜 |

试炼场是深色区域：语义色使用暗色变体，代码区不变。读者可以在设置里打开「简洁模式」，收起点阵、插画和庆祝动效。

## 5. 吉祥物与线程小机器人

- **小核**：屏幕脸的芯片机器人。身体是圆角方块（浅青渐变），屏幕是深色圆角矩形，LED 眼睛是青色竖条，头顶天线灯为琥珀色，两侧芯片引脚当手，底部两只脚，胸口有一个脉冲图标。三种表情：默认、给提示（头顶小灯泡）、庆祝（眯眼笑 + 星星）。源码见 `refactor/design/Characters.dc.html`。
- **线程小机器人**：小核的同款缩小版。屏幕上显示自己的 `threadIdx.x`，身体底部色条 = 所在线程块的分类色，搬运的是立体数据块。五种状态：写入（抱数据块）、检查后跳过（熄屏，头顶 z）、越界（倾斜 12°，屏幕变红，红色叹号）、重复计算（琥珀色 ×2 标）、等待同步（举手）。
- 插画线条 1.6–2.5px 深墨色；渐变只允许在小核身体和星星这类插画内部使用。
- 小核只出现在：关卡开头的故事、提示、庆祝、地图欢迎区。不出现在数据结论和表格旁边。

## 6. 图标与插画

- 图标用内联描边 SVG（1.5px，`currentColor`），不用 emoji，不引入图标字体。
- 示意图里的元素画法统一：线程 = 线程小机器人；数组元素 = 显存格子（顶部等宽地址 `c[3]`）；cache line = 一组格子外的括号「一车」；线程块 = 带色点和 `block N` 标签的浅色容器；越界区 = 红色虚线框 + 斜纹底。

## 7. 可访问性

- 文字对比度达到 WCAG AA（正文 4.5:1，大字 3:1）。上表的文字色已按此选择；新增颜色必须自查。
- 不靠颜色单独表达信息：越界 = 红 + 斜纹 + 叹号 + 文字；跳过 = 灰 + 虚线 + z；完成 = 青 + 对勾。
- 375px 宽度下页面不出现横向滚动；代码区内部可以横向滚动。
