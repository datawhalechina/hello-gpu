# 02 动效规范

动效只为解释因果服务：每段动效都要能回答「它让读者看懂了什么」，答不上来就删掉。

## 1. 四种用途

| 类型 | 用途 | 例子 | 时长 |
| --- | --- | --- | --- |
| 因果演示 | 展示一个操作带来的后果 | 线程机器人取数、相加、写回 | 每个子动作 400–800 ms |
| 状态过渡 | 参数改变后布局变化 | blockDim 从 4 改成 8，机器人重新分组 | 200–300 ms |
| 注意力引导 | 指出读者该看哪里 | 越界的机器人闪一下 | 150–250 ms，最多重复 2 次 |
| 反馈 | 操作结果和奖励 | 星星点亮、升级、徽章 | 300–600 ms；升级不超过 1.5 s，可跳过 |

## 2. 时长与缓动 token

| token | 值 | 用在 |
| --- | --- | --- |
| `--motion-instant` | 100 ms | 悬停、按下 |
| `--motion-fast` | 200 ms | 小元素状态变化 |
| `--motion-base` | 300 ms | 布局过渡、颜色变化 |
| `--motion-slow` | 500 ms | 场景切换、放大缩小 |
| `--motion-scrub` | 420 ms | 拖动时间轴时的补间（沿用 `useSceneClock`） |
| 讲解动画每步 | 1500 ms + 旁白字数 × 60 ms，上限 8 s | `ScenePlayer` 的 step |

- 进入用 `easeOutCubic`（CSS `cubic-bezier(0.33, 1, 0.68, 1)`），来回移动用 `easeInOutCubic`，离开用 ease-in。
- **弹跳只用于奖励和吉祥物**：星星、徽章、等级数字、小核表情可以用 `easeOutBack`（轻微过冲）；数据元素（机器人、格子、图表）一律不弹跳。
- 场景内的分段时序统一用 `docs/components/animation/easing.ts` 里的 `seg` / `segE`。
- 区域差异：新手村可以用全部效果；铸造城不用庆祝彩带以外的弹跳；试炼场只保留淡入和位移。

## 3. 编排规则

- **一次只动一件事**，或一组同类元素。同组元素错开 30–50 ms，总错开不超过 600 ms。
- **空间约定全站固定**：主机（CPU）在左，设备（GPU）在右；显存在下，计算单元在上；时间从左到右。读的箭头从内存指向计算，写反过来。
- **对象恒常**：同一个对象在不同场景外观一致；场景切换用放大或缩小衔接（例如从 grid 放大到 block），不硬切。
- **速度声明**：动画速度和真实耗时无关时，标注「动画速度不代表 GPU 耗时」。
- **可控**：超过 1 秒的动画都能暂停、单步、拖动；自动播放只在进入视口时开始，离开就暂停。
- **交互优先**：读者改参数时，数字先立即更新，图形再用 `--motion-base` 过渡，不让读者等动画。
- **当前位置**：地图上的「你在这」用呼吸光圈（缩放 0.8 → 1.8、透明度 0.7 → 0，1.8 s 循环），不用上下跳动。

## 4. 可访问性

- `prefers-reduced-motion: reduce` 时，所有位移、缩放、循环动画关闭，只保留淡入或直接切换；自定义 `@keyframes` 要单独处理。
- 闪烁频率低于每秒 3 次。
- 动效里的关键信息都要有文字等价物：讲解旁白用 `aria-live` 播报，状态变化写在结果说明里。

## 5. 性能

- 只对 `transform`、`opacity` 和颜色做动画。
- 单个场景的 SVG 元素不超过 2000 个，超过改用 Canvas。
- 动画状态写成时间的纯函数（state = f(t)），方便单测；沿用 `scripts/tests/*-animation.test.mjs` 的写法。

## 6. 奖励动效

- 拿星：星星依次点亮，每颗间隔 150 ms，放大到 1.15 再回落。
- 升级：深色卡片 + 六边形等级徽章 + 少量彩带，不超过 1.5 s，点击任意处跳过，不全屏遮挡。
- 新徽章：底部 Toast 滑入，3 s 后自动消失。
- 默认不播放声音；彩带可在设置里关闭。
