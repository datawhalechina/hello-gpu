# 04 游戏化规范

趣味来自「好奇 → 尝试 → 顿悟」的循环，游戏机制只给这个循环加节奏。任何机制都不能和「学会」冲突：如果一个机制能让人不学也拿高分，就改掉它。

## 1. 结构

- **区域**：新手村、铸造城、试炼场（无尽之塔本版不做）。区域从不上锁，只标推荐等级。
- **关卡**：数据在 `docs/course/outline.json`。URL 和存档用稳定的 `id` / `slug`；页面上的编号（如 1-4）由数据生成，中间插入新关卡不会破坏链接和进度。
- **Boss**：每个区域最后的综合挑战，通过后获得区域徽章。
- **副本**：挂在区域旁边的可选练习题，不占主线。

## 2. 经验值与等级

| 来源 | 经验值 |
| --- | --- |
| 完成关卡（检查点全部作答） | 100 |
| 每颗星 | 50（最多 3 颗） |
| Boss | 500 |
| 副本 | 每题 50–150 |
| Agent 支线 | 50 |
| 观摩模式完成真卡关卡 | 100（不得星） |
| 先猜 | 0（猜错也不扣） |

- 等级 Lv.N 需要累计 300 × (N − 1) XP；每 300 XP 升一级，不设上限。
- 定级测试给出的初始等级直接换算成经验值（Lv.10 = 2700 XP），在存档里标注来源「定级」。被豁免的关卡标为「已豁免」，不自动给星，可以随时回去拿星。
- 每颗星、每次完成只计一次；重复通关不重复加经验值。

## 3. 星级

- 每关三颗星，标准写在关卡的 `Mission` 里，并在 `challenge.ts`（模拟器关卡）或 `outline.json` 的实验室规则（真卡关卡）里用代码实现。
- ★1 结果正确（真卡关卡：多种形状都通过校验）；★2 达到效率目标；★3 最优或额外挑战（例如规则在换一种配置后依然成立）。
- **真卡关卡的效率目标用相对值**，不用绝对数字：例如「达到你这张卡实测峰值带宽的 70%」「比同一张卡上的 torch 实现快」。读者的卡可能是 RX 9070 XT、云上的 W7900D 或 Radeon 8060S，绝对数字没有可比性。
- 在挑战里看过答案，本关最高 2 星。

## 4. 徽章

每枚徽章都对应一项可以验证的能力，不发签到、连续天数这类徽章。首批：

| 徽章 | 获得条件 |
| --- | --- |
| 首次通关 | 完成第一关 |
| 零越界 | 在挑战里一次都没有越界写就拿到 3 星 |
| 识破假加速 | 在任意「识破」环节选对 |
| 同步大师 | 完成 1-9、1-10 的全部星 |
| 双语法 | 新手村同一关用 HIP 风格和 Python 风格都通关 |
| 双路线 | 铸造城或试炼场同一关用两条路线都通关 |
| 第一个 Agent | 完成 1-14 |
| 打败 torch | 在任意真卡关卡拿到「比 torch 快」的星 |
| 真机验证 | 第一次导入真卡实验室的通关码 |
| 区域毕业 | 通过对应区域的 Boss（每个区域一枚） |
| 图鉴收集家 | 收集一个区域的全部新术语 |

徽章的定义集中放在一个数据文件里（任务 F-07 落地），关卡只调用「发放徽章」接口。

## 5. 图鉴

- 每个新术语第一次以 `ConceptCard` 出现并进入视口后，收入图鉴。
- 术语的统一定义放在 `docs/course/glossary.json`（任务 F-07 建立），关卡里的概念卡引用它，不在各关重复写定义。
- 「我的成长」页的图鉴可以点回第一次学到它的关卡。

## 6. 吉祥物与轻剧情

- 小核负责引导、给提示、庆祝；每句台词不超过 30 字；不卖萌过度；不出现在数据结论旁边。
- 世界观：GPU 是一座芯片工坊城。每个区域一句主线委托写在区域首页，Boss 是委托的高潮。剧情只是调味料，每关最多两句。

## 7. 进度与存档（无后端）

- 所有进度只存在读者浏览器的 localStorage；首次进入时向浏览器申请持久存储（`navigator.storage.persist()`），降低被自动清理的概率。
- 换设备：导出存档文件（JSON）或复制存档码，到新设备导入。
- 「我的成长」页提醒：距离上次导出超过 14 天时，建议再导出一次。
- 不做排行榜、不做自动同步、不收集任何个人数据。

## 8. 防误导与边界

- 模拟数字一律标注「模拟」，关卡末尾给出真实硬件的对照（来自实验档案馆）。
- 游戏里的简化要在「深入一点」里说明简化了什么，例如模拟器的 cache line 大小和延迟都是示意值。
- 不做制造焦虑的机制：没有倒计时、没有生命值、没有断签惩罚、没有「再不学就掉级」。
- 庆祝动效可以关闭；「简洁模式」下只保留文字反馈。
