# R-07 真机验证与档案：试炼场 3-5、3-6

## 目标

在装有 AMD GPU 和 ROCm 的机器上跑通 3-5 访存进阶、3-6 wave 内协作 的实验室 Notebook（每条路线都跑），修正问题，把参考运行记录存进档案馆，替换网页里的「[待实测]」和示意数据。

## 背景

- 07 第 6、12 节：每本 Notebook 要能「Restart Kernel and Run All」从头跑通；RX 9070 XT 上不超过 10 分钟。
- 星级阈值要让认真完成的读者能拿到，又不能让朴素实现直接拿三星。

## 要做的事

1. 确认环境：`rocminfo`、`hg.device_card()`；在完成记录里写下设备和软件版本。
2. 每本 Notebook「Restart & Run All」，记录耗时；出错就修改源文件，重新 `npm run nb:build`。
3. 运行交成绩单元，用通关链接打开本地站点（`npm run docs:dev`），确认导入和星级判定正确；调整 `lab.stars` 阈值时在完成记录里写明理由。
4. 把参考实现的运行记录存成档案条目（L-04 格式），确认观摩模式能回放。
5. 替换对应网页里的「[待实测]」和示意数据，EvidenceCard 指向档案条目。

## 验收标准

- [ ] 每本 Notebook 在真卡上从头跑通，耗时写进完成记录
- [ ] 通关链接导入后星级判定正确
- [ ] 每关每条路线至少有一条档案条目，观摩模式可以回放
- [ ] 对应网页里没有剩余的「[待实测]」（确实测不了的在完成记录里说明）
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- 在有 AMD GPU 的机器上运行 Notebook
- `npm run nb:check`
- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
