# FG-04 2-4 性能的天花板（峰值与 Roofline）

## 目标

按关卡模板做出「2-4 性能的天花板：峰值与 Roofline」网页，读者学完能回答：这张卡最多能多快？我的 kernel 离上限多远？

## 背景

- 大纲条目：`forge-roofline`（推荐 Lv.12，约 25 分钟，需要真卡）。
- 硬件落点：实测峰值带宽（拷贝测试）和峰值算力（FMA 测试）；Roofline 模型
- 核心交互：用自己测出的峰值画出这张卡的屋顶线，再拖动算子点判断瓶颈
- 两条路线共用（`routes: shared`），不使用 RouteBlock，只生成一份 Notebook。
- 本关的实验室 Notebook 由 FG-LAB-04 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（铸造城语气：工程师之间的交流，简洁）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/forge/roofline.md`。
2. Roofline 组件：读取「我的 GPU 卡片」里的峰值（没有时用档案馆参考值），读者拖动算子点判断瓶颈。
3. 写 `docs/forge/roofline/index.md`：11 项骨架；挑战用 `LabCard`；Mission 的星级标准从 outline 的 `lab.stars` 读取。
4. 本关可视化放 `docs/forge/roofline/scenes/`。需要真实数据的地方从档案馆读取；还没有数据时用标注「示意」的数据，并在完成记录里列出，由 R-01 替换。
5. 正文里的实测数字一律引用档案条目；暂时没有的写「[待实测]」。
6. 新术语登记进 glossary（首次出现链接概念卡）。
7. 把 outline.json 里 `forge-roofline` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
