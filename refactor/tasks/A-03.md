# A-03 可选：接入读者自己的大模型

## 目标

1-14 的可选环节：读者填入自己的 API Key，让大模型代替规则策略做「思考」这一步，再和规则 Agent 对比。

## 背景

- 没有后端，也不经过任何中转服务器，浏览器直接请求读者填写的服务商。各服务商对浏览器直连（CORS）的支持不同，要实测或引用官方文档确认。

## 要做的事

1. 支持 OpenAI 兼容接口（自填 base URL 和模型名）和 Anthropic 接口。
2. Key 只存在 sessionStorage；页面写明「Key 只在你的浏览器里，直接发给你填写的服务商」。
3. 大模型只输出下一步行动（结构化 JSON），页面校验后才执行；输出不合法时提示并停止。
4. 在完成记录里列出哪些服务商可以浏览器直连（附出处）；不能直连时提示读者跳过或用本地代理。
5. 不提供任何默认 Key。

## 验收标准

- [ ] 不填 Key 时这一节完全可选，不影响通关和星级
- [ ] Key 不出现在 localStorage、URL 或日志里
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
