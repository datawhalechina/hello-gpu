# X-01 副本框架

## 目标

建立副本的数据、页面框架和外部题链接卡：副本大厅、单个副本的布局、经验值发放。

## 背景

- 副本以自研题为主；外部题只链接原题，写原创题解。
- 许可证：LeetGPU 题库是 CC BY-NC-ND 4.0，不能翻译或改编题面；GPU MODE reference-kernels 用自定义许可证，不复制内容；GPU-Puzzles 是 MIT，可以改编，要署名。
- outline.json 的 `exercises` 列了首批副本名称。

## 要做的事

1. 扩展 outline.json 的 `exercises`：每道题加 id、slug、xp（50–150）、难度、关联关卡、运行环境（模拟器 / 真卡）；同步修改 `scripts/refactor/outline-md.mjs` 生成的副本表。
2. `/dungeon/` 大厅：按区域分组，显示完成情况。
3. 单个副本页 `docs/dungeon/<slug>/index.md` 使用 `layout: dungeon`（复用 StageLayout 的头部和状态栏，数据来自 exercises）；骨架：题目 → 挑战（Sandbox 或 LabCard）→ 提示阶梯 → 题解（通关或看答案后展开）→ 证据。
4. `ExternalProblem.vue`：只显示题名、来源、许可证和链接，不复制题面。
5. 让 F-14 的检查覆盖副本页；地图和区域首页的副本入口启用。

## 验收标准

- [ ] 大厅、地图上的副本入口都能用
- [ ] 外部题卡片里没有题面文字
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /dungeon/`，逐张看过截图，把截图目录写进完成记录
