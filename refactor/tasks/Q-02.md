# Q-02 定级测试页面 /placement/

## 目标

实现定级测试：逐组作答、即时解释、给出推荐起点和等级，确认后写入进度。

## 背景

- 计分逻辑在 Q-01。

## 要做的事

1. 流程：开始 → 新手村组 →（达标）铸造城组 →（达标）试炼场组 → 结果。可以随时退出。
2. 结果页：推荐区域和关卡、推荐等级、豁免关卡列表（可以取消豁免）；点「确认」才写入 progress，来源标为「定级」。
3. 重新测试会覆盖上次定级，要二次确认。
4. 结果页链接到地图，并高亮推荐关卡。

## 验收标准

- [ ] 零基础读者 2 分钟内能做完并被推荐到 1-1
- [ ] 豁免的关卡在地图上显示「已豁免」，没有星
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /placement/`，逐张看过截图，把截图目录写进完成记录
