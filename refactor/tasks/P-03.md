# P-03 区域首页 /novice/、/forge/、/trial/

## 目标

实现三个区域首页：主线委托、关卡列表、推荐等级、运行环境、路线选择（铸造城和试炼场）、副本入口。

## 背景

- 数据全部来自 outline.json（zones、stages、exercises）；04 第 6 节规定每个区域首页有一句主线委托。

## 要做的事

1. 共用组件 `ZoneHome.vue`；区域装扮的小核和一句主线委托。
2. 关卡列表按 arc 分组，显示每关「学完能回答」。
3. 铸造城和试炼场：入口选择 HIP 或 Triton 路线（写入偏好），用 outline 数据生成「两条路线怎么分」的表格。
4. 副本入口链接到 `/dungeon/` 对应分组。

## 验收标准

- [ ] 区域首页没有手写的关卡信息
- [ ] 选择路线后，进入该区域任何 split 关卡都显示所选路线
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /novice/ /forge/ /trial/`，逐张看过截图，把截图目录写进完成记录
