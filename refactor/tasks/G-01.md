# G-01 作者验收：视觉风格与组件

## 目标

作者看一遍组件预览页和迷你关卡，确认视觉、动效、交互方向，再开始批量做关卡。

## 背景

- 批量做关卡之前最后一次调整视觉的机会。之后再改风格，返工量会随关卡数增加。

## 要做的事

1. `npm run docs:dev`，打开 `/preview/kit/` 和 `/preview/kit/stage-demo/`，在电脑和手机上各走一遍。
2. 通过：对会话说「验收任务 G-01：通过」。
3. 不通过：说「验收任务 G-01：不通过（原因：……）」，会话会把问题拆成修复任务。

## 验收标准

- [ ] 风格符合「精致科技风 + 有亲和力的吉祥物」
- [ ] 关卡布局、状态栏、奖励反馈可以作为后续关卡的基础

## 验证方式

- 作者人工验收
