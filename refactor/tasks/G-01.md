# G-01 作者验收：视觉风格与组件

## 目标

作者看一遍组件预览页和迷你关卡，确认视觉、动效、交互方向，再开始批量做关卡。

## 背景

- 批量做关卡之前最后一次调整视觉的机会。之后再改风格，返工量会随关卡数增加。

## 要做的事

1. 在本地查看本段工作：`git fetch origin && git switch work/G-01 && npm install && npm run docs:dev`（也可以直接在 GitHub 的 PR 页面看改动和截图说明）。
2. 打开 `/preview/kit/` 和 `/preview/kit/stage-demo/`，在电脑和手机上各走一遍。
3. 在本段 PR 里给出结论：没问题就合并 PR（合并即验收通过，任务状态由 GitHub Actions 自动更新）；有问题在 PR 里评论或 Request changes，执行者修改后会在 PR 里回复。

## 验收标准

- [ ] 风格符合「精致科技风 + 有亲和力的吉祥物」
- [ ] 关卡布局、状态栏、奖励反馈可以作为后续关卡的基础
