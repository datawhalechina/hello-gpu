# L-07 我的 GPU 卡片

## 目标

读者在 2-1 运行 `hg.device_card()` 得到导入码，导入网页后保存为「我的 GPU 卡片」；1-2 的全景图和 2-4 的 Roofline 用上真机参数。

## 背景

- 1-2 的全景图组件在 NV-02 已支持通过参数重绘。

## 要做的事

1. `device.ts`：解码 `HGCARD1.` 并校验，存进 progress（可以存多张卡，选一张为当前）。
2. `DeviceCard.vue`：名称、gfx、CU 数、wave 大小、显存、峰值带宽和算力（2-4 测出后补充）、软件版本。
3. 1-2 全景图读取当前卡片；没有卡片时用 `hardware.json` 的默认值并标注来源。
4. 「我的成长」页显示卡片。

## 验收标准

- [ ] 用伪造的导入码（没有 GPU 时生成）走通导入 → 全景图更新
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过
