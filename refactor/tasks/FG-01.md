# FG-01 2-1 开工准备（认识你的 GPU）

## 目标

按关卡模板做出「2-1 开工准备：认识你的 GPU」网页，读者学完能回答：怎么在云上或本地拿到能用的 AMD GPU？我的卡有多少个 CU、wave 多大、显存多少？

## 背景

- 大纲条目：`forge-your-gpu`（推荐 Lv.10，约 20 分钟，需要真卡）。
- 硬件落点：用 rocminfo、rocm-smi 读出真机参数，填进新手村的全景图
- 核心交互：一键检查脚本 + 「我的 GPU 卡片」：自动填好 CU 数、wave 大小、显存容量，导入网页后全景图换成真机参数
- 两条路线共用（`routes: shared`），不使用 RouteBlock，只生成一份 Notebook。
- 本关的实验室 Notebook 由 FG-LAB-01 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（铸造城语气：工程师之间的交流，简洁）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/forge/your-gpu.md`。
2. 在页面里嵌入 DeviceCard 导入（L-07），导入后链接回 1-2 全景图查看真机参数。
3. 链接实验环境指南（L-06）。
4. 写 `docs/forge/your-gpu/index.md`：11 项骨架；挑战用 `LabCard`；Mission 的星级标准从 outline 的 `lab.stars` 读取。
5. 本关可视化放 `docs/forge/your-gpu/scenes/`。需要真实数据的地方从档案馆读取；还没有数据时用标注「示意」的数据，并在完成记录里列出，由 R-01 替换。
6. 正文里的实测数字一律引用档案条目；暂时没有的写「[待实测]」。
7. 新术语登记进 glossary（首次出现链接概念卡）。
8. 把 outline.json 里 `forge-your-gpu` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
