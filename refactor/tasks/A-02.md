# A-02 浏览器里运行读者写的 Agent 代码（Pyodide）

## 目标

让读者在 1-14 里用 Python 补全 ReAct 循环的三个空并真正运行：Pyodide 按需加载、文件自托管，读者的代码调用模拟器工具。

## 背景

- 09 第 3 节：Pyodide 文件自托管，不依赖海外 CDN。Pyodide 体积较大，实际大小以本任务实测为准。
- 加载方式要保证首屏不受影响：只在读者点「运行我的 Agent」时加载。

## 要做的事

1. 用精确版本的 `pyodide` npm 包，构建时把运行所需文件复制到站点的静态目录（不提交进 git）；在完成记录里写明增加的部署体积。
2. 给 Python 侧暴露模拟器工具（`run_kernel`、`measure` 等，调用 A-01 的实现）。
3. `AgentCode.vue`：三个空的编辑、运行、加载进度；语法错误、运行时错误给中文提示；加载失败时退化为「看规则 Agent 回放」。
4. 在 M-05 的部署检查里要用到体积数据，写进完成记录。

## 验收标准

- [ ] 首屏不加载 Pyodide
- [ ] 三个空补对后，Agent 在模拟器上把配置调到三星
- [ ] 加载失败时页面仍然可以学完本关
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /preview/kit/`，逐张看过截图，把截图目录写进完成记录
