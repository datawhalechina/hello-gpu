# M-05 部署前检查

## 目标

确认新版在 CI 和部署环境里能完整构建：依赖、体积、base 路径、两个部署目标（GitHub Pages 和 EdgeOne）。只检查和修改配置，不合并到 main、不部署。

## 背景

- `package-lock.json` 在 `.gitignore` 里，CI 每次重新解析依赖，所以依赖必须写精确版本。Pyodide 等静态文件会增加部署体积（A-02 记录了数据）。

## 要做的事

1. 在一个干净目录里模拟 CI：全新安装依赖、`npm run docs:build`，记录耗时和产物体积。
2. 检查 `deploy.yml`、`notebook-learning.yml`、`refactor-check.yml` 和 EdgeOne 配置是否需要调整（新脚本、新静态文件、Playwright 不应在部署时安装）。
3. 确认 base 路径 `/hello-gpu/` 下所有新版资源都能加载。

## 验收标准

- [ ] 干净环境里构建通过
- [ ] 部署产物体积和变化写进完成记录
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
