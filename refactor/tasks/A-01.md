# A-01 Agent 控制台与规则 Agent

## 目标

实现 AgentConsole 组件和一个在模拟器上运行的规则 Agent（ReAct：思考 → 行动 → 观察），供 1-13、1-14 和新手村 Boss 使用。

## 背景

- Agent 用的工具就是前面学过的操作：运行 kernel、计时、看访存。工具在模拟器上运行，结果是确定的。

## 要做的事

1. `docs/course/agent/`（纯 TS）：ReAct 循环框架，包括状态、工具（`run_kernel`、`measure`、`inspect_memory` 等，内部调用 `docs/sim`）、规则策略；每一步产生 `{ thought, action, observation }`。
2. `AgentConsole.vue`：逐条显示思考、行动、观察；单步、自动播放、回放；「你来当 Agent」模式下读者选下一步，再和规则 Agent 的选择对比。
3. 单测：规则 Agent 在固定任务（调 block 大小和访问步长）上收敛到三星配置；有步数上限。
4. 在 `/preview/kit/` 补上演示。

## 验收标准

- [ ] 规则 Agent 每一步的 thought 都是读得懂的中文
- [ ] 回放和单步能用键盘操作
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /preview/kit/`，逐张看过截图，把截图目录写进完成记录
