# TR-13 试炼场 Boss：毕业考

## 目标

按关卡模板做出「试炼场 Boss：综合」网页，读者学完能回答：综合运用试炼场的全部知识

## 背景

- 大纲条目：`trial-boss`（推荐 Lv.30，约 240 分钟，需要真卡）。
- 硬件落点：—
- 核心交互：选一个 PyTorch 模型里的热点算子，人加 Agent 联合优化：用计数器给出瓶颈证据，逼近 Roofline 上限，替换进模型并用前向 A/B 证明收益，提交可复现的报告
- 分路线（`routes: split`）：
  - 两条路线共用：任务和评分标准
  - HIP 路线：用 HIP 完成
  - Triton 路线：用 Triton 完成
- 本关的实验室 Notebook 由 TR-LAB-13 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（试炼场语气：精确，引用一手资料）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/trial/boss.md`。
2. 写 `docs/trial/boss/index.md`：11 项骨架；挑战用 `LabCard`；实现部分用 `<RouteBlock route="hip">` / `<RouteBlock route="triton">`，两块的小标题和顺序一致；共用部分直接写；Mission 的星级标准从 outline 的 `lab.stars` 读取。
3. 本关可视化放 `docs/trial/boss/scenes/`。需要真实数据的地方从档案馆读取；还没有数据时用标注「示意」的数据，并在完成记录里列出，由 R-10 替换。
4. 正文里的实测数字一律引用档案条目；暂时没有的写「[待实测]」。
5. 新术语登记进 glossary（首次出现链接概念卡）。
6. 把 outline.json 里 `trial-boss` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
