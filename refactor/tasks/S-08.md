# S-08 访存视图 MemoryView

## 目标

实现访存视图：一个 wave 一次访存的地址、cache line「车次」和事务数，服务 1-7、1-8。

## 背景

- 数据来自 S-03 的 `analyzeMemory`。

## 要做的事

1. 显存格子按 cache line 分段；当前访存的地址高亮；显示「这次搬了 N 车，理想是 M 车」。
2. 可以切换元素大小（4 B / 2 B）和 cache line 大小（示意值）。
3. 和 RobotGrid 联动：点一个线程，看它访问的地址。
4. 在 `/preview/kit/` 补上演示。
