# TR-06 3-6 wave 内协作（跨 lane 操作）

## 目标

按关卡模板做出「3-6 wave 内协作：跨 lane 操作」网页，读者学完能回答：不经过 LDS，wave 内的线程怎样交换数据？

## 背景

- 大纲条目：`trial-wave-cooperation`（推荐 Lv.25，约 60 分钟，需要真卡）。
- 硬件落点：跨 lane 操作（shuffle、DPP），wave 级归约与扫描
- 核心交互：实测 LDS 归约和 wave 内归约的差别；写一个前缀和
- 分路线（`routes: split`）：
  - 两条路线共用：跨 lane 操作原理
  - HIP 路线：直接调用 shuffle、DPP
  - Triton 路线：tl.reduce、tl.associative_scan，并在汇编里找到对应的跨 lane 指令
- 本关的实验室 Notebook 由 TR-LAB-06 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（试炼场语气：精确，引用一手资料）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/trial/wave-cooperation.md`。
2. 写 `docs/trial/wave-cooperation/index.md`：11 项骨架；挑战用 `LabCard`；实现部分用 `<RouteBlock route="hip">` / `<RouteBlock route="triton">`，两块的小标题和顺序一致；共用部分直接写；Mission 的星级标准从 outline 的 `lab.stars` 读取。
