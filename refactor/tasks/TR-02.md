# TR-02 3-2 读懂 ISA（源码与机器指令）

## 目标

按关卡模板做出「3-2 读懂 ISA：源码与机器指令」网页，读者学完能回答：我写的 HIP / Triton 最后变成了哪些机器指令？

## 背景

- 大纲条目：`trial-read-isa`（推荐 Lv.21，约 60 分钟，需要真卡）。
- 硬件落点：s_ 标量指令与 v_ 向量指令、访存指令、s_waitcnt 等待
- 核心交互：源码与汇编对照视图：点一行源码，高亮对应的指令
- 分路线（`routes: split`）：
  - 两条路线共用：汇编本身两条路线一样
  - HIP 路线：从 hipcc 的输出看汇编
  - Triton 路线：从 Triton 的中间表示一路看到汇编
- 本关的实验室 Notebook 由 TR-LAB-02 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（试炼场语气：精确，引用一手资料）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/trial/read-isa.md`。
2. 源码与汇编对照视图：点一行源码，高亮对应指令；数据来自真实编译输出（R-06 之前用标注「示意」的样例）。
3. 写 `docs/trial/read-isa/index.md`：11 项骨架；挑战用 `LabCard`；实现部分用 `<RouteBlock route="hip">` / `<RouteBlock route="triton">`，两块的小标题和顺序一致；共用部分直接写；Mission 的星级标准从 outline 的 `lab.stars` 读取。
4. 本关可视化放 `docs/trial/read-isa/scenes/`。需要真实数据的地方从档案馆读取；还没有数据时用标注「示意」的数据，并在完成记录里列出，由 R-06 替换。
5. 正文里的实测数字一律引用档案条目；暂时没有的写「[待实测]」。
6. 新术语登记进 glossary（首次出现链接概念卡）。
7. 把 outline.json 里 `trial-read-isa` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
