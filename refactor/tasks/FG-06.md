# FG-06 2-6 路线进阶（写法与配置）

## 目标

按关卡模板做出「2-6 路线进阶：写法与配置」网页，读者学完能回答：怎样把 kernel 的写法和启动配置调到合适？

## 背景

- 大纲条目：`forge-route-advanced`（推荐 Lv.14，约 30 分钟，需要真卡）。
- 硬件落点：每组大小、每个线程的工作量和 wave 数，决定了硬件能不能被用满
- 核心交互：HIP 路线：主机端 API、stream、错误检查与 launch 配置；Triton 路线：BLOCK_SIZE、num_warps 与 autotune
- 分路线（`routes: split`）：
  - 两条路线共用：「配置怎样影响硬件利用」的讲解
  - HIP 路线：主机端 API、stream、错误检查、launch 配置
  - Triton 路线：BLOCK_SIZE、num_warps、autotune
- 本关的实验室 Notebook 由 FG-LAB-06 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（铸造城语气：工程师之间的交流，简洁）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/forge/route-advanced.md`。
