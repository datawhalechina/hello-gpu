# F-10 关卡布局 StageLayout

## 目标

实现关卡专注模式的布局：关卡头和顶部状态栏都从 `outline.json` 生成，正文只写内容。

## 背景

- 06 第 2、3 节（frontmatter 和骨架）；03 第 3 节里 StageLayout 的关键行为；设计稿 Stage 画板。
- 试点的关卡头：`docs/preview/ui/StageHeader.vue`。

## 要做的事

1. 根据 frontmatter `stage` 从 outline 读编号、标题、副标题、区域、推荐等级、时长、真卡要求；前置关卡取 outline 里的上一关。
2. 顶部状态栏（吸顶）：回地图、区域名、关卡号和标题、进度点（按正文 h2 生成，滚动时高亮当前段）、等级与经验值、本关星级、写法 / 路线切换位（F-11 填充）、提示按钮位（F-12 填充）。
3. 关卡头：读者等级低于推荐等级时显示一句温和提示，不上锁；前置关卡链接显示是否已完成。
4. 底部：上一关 / 下一关（按 outline 顺序）、回到区域首页。
5. `data-zone` 取关卡所在区域；outline 里 status 为 `draft` 时显示「测试版」标记。
6. frontmatter `stage` 在 outline 里找不到时，构建报错。
7. 用 `docs/novice/assign-threads/index.md` 做一个占位关卡验证布局（NV-03 会替换它的正文）。

## 验收标准

- [ ] 占位关卡的头部、状态栏、上下关链接都正确
- [ ] 进度点随滚动高亮，键盘可以跳到各段
- [ ] 375px 下状态栏不溢出（次要信息折叠）
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /novice/assign-threads/`，逐张看过截图，把截图目录写进完成记录
