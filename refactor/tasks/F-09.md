# F-09 内容组件（下）：ConceptCard、Checkpoint、EvidenceCard

## 目标

迁移并重做 ConceptCard、Checkpoint、EvidenceCard，接入术语表、图鉴和关卡完成逻辑。

## 背景

- 试点版本在 `docs/preview/ui/`。术语表和徽章在 F-07 建好。

## 要做的事

1. ConceptCard：props `term`（glossary 的键），定义从术语表读，不在页面里重复写；进入视口后调用 `collectTerm`；显示比喻和比喻边界；链接到手册。
2. Checkpoint：2–3 道题，每个选项都有解释；全部作答后调用 `completeStage`（关卡 id 从页面 frontmatter 读）。
3. EvidenceCard：`kind` = simulated / measured / mixed；measured 时显示硬件、软件版本、日期和档案条目链接（档案馆在 L-04 建立，先支持传入条目 id）。
4. 在 `/preview/kit/` 补上三个组件的演示。

## 验收标准

- [ ] ConceptCard 引用不存在的术语键时，开发环境里显示明显的警告，构建时报错
- [ ] Checkpoint 全部作答后关卡标记完成并加 100 XP，重复作答不重复加
- [ ] 键盘能完成全部操作
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过
