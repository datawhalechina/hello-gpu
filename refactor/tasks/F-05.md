# F-05 吉祥物小核与线程机器人组件

## 目标

把设计稿里的小核和线程小机器人做成可复用的 SVG 组件，表情、装扮和状态由 props 控制。

## 背景

- 设计稿：`refactor/design/` 里的 Characters 画板（含小核的三套区域装扮和线程机器人的 5 种状态），SVG 可以直接复制。
- 01 第 6 节（吉祥物）、第 7 节（线程机器人状态）；02 规定只有吉祥物和奖励可以用弹性动效。

## 要做的事

1. `Mascot.vue`：props `mood`（以设计稿实际表情为准）、`outfit`（default / helmet / visor，默认跟随所在区域）、`size`；可选对话气泡 slot（台词不超过 30 字）。
2. `ThreadBot.vue`：props `state`（按 01 第 7 节的 5 种状态）、`color`（分类色 token）、`label`（如线程号）；状态不能只靠颜色区分。
3. 待机动效（呼吸、眨眼）遵守减弱动效设置。
4. 在 kit 入口全局注册；新建 `/preview/characters/` 展示全部状态和装扮。

## 验收标准

- [ ] 和设计稿对照，外形和配色一致（完成记录里附对比截图路径）
- [ ] 每个状态都有 `aria-label` 或可读文字
- [ ] 预览页放 200 个 ThreadBot 时滚动不卡
- [ ] 减弱动效下没有位移动画
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /preview/characters/`，逐张看过截图，把截图目录写进完成记录
