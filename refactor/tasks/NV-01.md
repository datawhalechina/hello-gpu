# NV-01 1-1 一千道加法（少数强核 vs 大量小核）

## 目标

按关卡模板做出「1-1 一千道加法：少数强核 vs 大量小核」，读者学完能回答：GPU 为什么快？什么样的任务适合并行？

## 背景

- 大纲条目：`docs/course/outline.json` 的 `novice-thousand-additions`（推荐 Lv.1，约 10 分钟，模拟器 不用）。
- 学完能回答：GPU 为什么快？什么样的任务适合并行？
- 硬件落点：CPU 是少数强大的核心，GPU 是成千上万个简单的执行通道
- 核心交互：分工竞速：1 个「教授」和 1000 个「学徒」做加法；换成有依赖的累加，看并行为什么失效
- 本关没有 Agent 支线。
- 这是读者见到的第一关，也负责教会读者「怎么玩」：任务卡、先猜、星级各出现一次，并用一两句话说明。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（新手村语气）、`03-interaction.md` 的组件登记表；读上一关的页面，保持口吻、比喻和例子连贯（新手村只用「向量加法」和「求和」两个例子）。
2. 设计「分工竞速」场景：1 个「教授」和 1000 个「学徒」做加法，读者可以调任务数量；换成有依赖的累加后，看并行为什么失效。用 ScenePlayer 或本关 scenes 组件实现。
3. 完成本关时发放「首次通关」徽章（徽章条件已在 F-07 定义，确认能触发）。
4. 写 `docs/novice/thousand-additions/index.md`：frontmatter 为 `layout: stage`、`stage: novice-thousand-additions`、`newTerms`、`evidence: simulated`；按 06 第 3 节的 11 项骨架写正文；代码用 `<LangCode>` 同时给 HIP 风格和 Python 风格。
5. 本关专属的可视化放 `docs/novice/thousand-additions/scenes/`；只用登记过的组件，需要新组件时先写进完成记录的「待确认」。
6. 挑战用登记过的交互组件实现三颗星的判定；判定逻辑写成纯函数放 `docs/novice/thousand-additions/challenge.ts`，单测 `scripts/tests/novice-thousand-additions.test.mjs`。
7. 新术语登记进 `docs/course/glossary.json`（每关不超过 3 个）。
8. 把 outline.json 里 `novice-thousand-additions` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
