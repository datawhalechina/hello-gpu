# S-02 模拟器 L2：锁步解释器与 Worker

## 目标

实现锁步执行的解释器：wave 切分、执行掩码、barrier、数据竞争检测、事件流，以及 Web Worker 封装。

## 背景

- 执行模型见 08 第 4 节，事件格式见第 5 节，运行方式见第 6 节。

## 要做的事

1. `lockstep.ts`：按 08 第 4 节执行；输出 SimEvent 流和最终数组状态；越界、在分支里同步、超出步数上限按规定处理；随机种子可以打乱 block 顺序。
2. `worker.ts` + `client.ts`：主线程用 Promise 调用，可以超时取消；测试环境直接调用同步接口。
3. 最小试验台 `/preview/sim/`：文本框 + 运行 + 打印事件，方便后续任务调试。
4. 单测：至少 5 个手算标准例（vector add、带分支、块内反转 + barrier、去掉 barrier 后的竞争、树状归约），两种写法的结果和事件流相同；性能用例记录 1024 线程 × 100 步的耗时，超过 150 ms 才判失败（留出机器差异）。

## 验收标准

- [ ] 08 第 4 节每条规则都有单测
- [ ] 同样的输入和种子，事件流逐项相同
- [ ] 在 `/preview/sim/` 通过 Worker 运行，页面不卡顿
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run docs:dev` 打开 `/preview/sim/` 手动运行几个例子
