# FG-11 2-11 把算子接回 PyTorch（自定义算子）

## 目标

按关卡模板做出「2-11 把算子接回 PyTorch：自定义算子」网页，读者学完能回答：怎样把自己的 kernel 注册成 PyTorch 算子，并在模型里替换？

## 背景

- 大纲条目：`forge-torch-integration`（推荐 Lv.18，约 35 分钟，需要真卡）。
- 硬件落点：—
- 核心交互：注册自定义算子；在一个小模型里替换，校验数值并测一次前向的端到端耗时
- 分路线（`routes: split`）：
  - 两条路线共用：在模型里替换、校验、测前向
  - HIP 路线：编译成 C++/HIP 扩展再注册
  - Triton 路线：用 torch.library 直接包装 Triton kernel
- 本关的实验室 Notebook 由 FG-LAB-11 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。
