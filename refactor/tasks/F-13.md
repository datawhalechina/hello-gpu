# F-13 奖励反馈：Toast、StarBurst、LevelUp

## 目标

实现三种奖励反馈和「简洁模式」（只保留文字反馈）。

## 背景

- 02 第 6 节（奖励动效参数）；04 第 8 节（庆祝动效可以关闭）。

## 要做的事

1. progress 发星、升级、得徽章、收入图鉴时发出事件；`RewardLayer.vue` 挂在新版两个布局上统一处理。
2. Toast（经验值、图鉴）、StarBurst（得星，小核庆祝）、LevelUp（升级卡片，可关闭）。
3. 同时触发多个奖励时排队播放，不叠在一起。
4. 简洁模式和减弱动效下只显示文字；奖励文字用 `aria-live` 播报。
5. 在 `/preview/kit/` 放触发按钮演示。

## 验收标准

- [ ] 连续得 3 颗星并升级时，动画按顺序播放，总时长符合 02 的规定
- [ ] 屏幕阅读器能读到奖励文字
- [ ] 简洁模式下没有动画
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过
