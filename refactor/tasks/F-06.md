# F-06 新版通用页面外壳 HgLayout

## 目标

实现新版非关卡页面（地图、前言、我的成长、手册等）共用的外壳：顶栏、点阵背景、区域换装、亮暗切换、页脚。

## 背景

- 设计稿：`refactor/design/` 的 Main、Map、Me 画板。
- F-02 已注册 `layout: hg` 的占位组件，本任务换成正式实现。

## 要做的事

1. 顶栏：Logo、地图、手册、我的成长、等级与经验值芯片、亮暗切换；手机端收起为菜单按钮。
2. 内容区：点阵背景、最大宽度、frontmatter `zone` 决定 `data-zone`（没有时用默认主题）。
3. 页脚：项目链接、旧版教程入口（先指向 `/`，M-01 后改为 `/v1/`）、一句隐私说明「进度只存在你的浏览器里」。
4. 等级芯片读 `useProgress()`；数据加载前显示占位，不闪烁。

## 验收标准

- [ ] `/world/`、`/preface/`、`/me/`、`/handbook/` 四个占位页都用上新外壳
- [ ] 375px 下顶栏不溢出，菜单能用键盘打开和关闭
- [ ] 亮暗切换和 VitePress 原有的切换保持同步
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /world/ /me/`，逐张看过截图，把截图目录写进完成记录
