# L-04 实验档案馆 /lab/

## 目标

建立实验档案馆：真实测量数据的格式、存放位置和浏览页。正文里的实测数字都从这里引用。

## 背景

- 09 第 4 节：实测数字只能来自档案条目。

## 要做的事

1. 数据格式 `docs/lab/data/<stage>/<route>-<device>-<date>.json`：凭证字段、完整环境、原始样本、Notebook 关键输出（文本 / 表格 / 图表数据）、采集人和日期。写 JSON Schema 和校验脚本，加入 `refactor:check`。
2. 浏览页 `/lab/`：按区域、关卡、设备筛选；每条记录可以展开看详情。
3. EvidenceCard 的 measured 模式链接到档案条目。
4. 旧仓库里已有的实测记录（如 `code/part2-kernels/chapter*/evidence/`）不自动迁入；在完成记录里列出可以迁移的候选，交给 R 任务处理。
5. 放一份示例条目到 `docs/lab/data/_example/`，标注「示例，不是实测」。

## 验收标准

- [ ] 示例条目能在浏览页正确显示
- [ ] schema 校验已加入 refactor:check
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /lab/`，逐张看过截图，把截图目录写进完成记录
