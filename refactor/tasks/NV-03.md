# NV-03 1-3 给线程派活（kernel 与线程）

## 目标

按关卡模板做出「1-3 给线程派活：kernel 与线程」，读者学完能回答：kernel 是什么？一份代码怎样让许多线程各做一份？

## 背景

- 大纲条目：`docs/course/outline.json` 的 `novice-assign-threads`（推荐 Lv.2，约 10 分钟，模拟器 L1）。
- 学完能回答：kernel 是什么？一份代码怎样让许多线程各做一份？
- 硬件落点：每个线程最终跑在 SIMD 的一条 lane 上
- 核心交互：沙盒填空：写出 i = ?，让每个线程拿到自己的元素
- 本关没有 Agent 支线。
- 这是读者第一次用代码沙盒。F-10 在这个路径留了占位页，直接替换正文。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（新手村语气）、`03-interaction.md` 的组件登记表；读上一关的页面，保持口吻、比喻和例子连贯（新手村只用「向量加法」和「求和」两个例子）。
2. 沙盒填空：读者写出 `i = ?`，让每个线程拿到自己的元素；RobotGrid 展示结果。
3. 写 `docs/novice/assign-threads/index.md`：frontmatter 为 `layout: stage`、`stage: novice-assign-threads`、`newTerms`、`evidence: simulated`；按 06 第 3 节的 11 项骨架写正文；代码用 `<LangCode>` 同时给 HIP 风格和 Python 风格。
4. 本关专属的可视化放 `docs/novice/assign-threads/scenes/`；只用登记过的组件，需要新组件时先写进完成记录的「待确认」。
5. `docs/novice/assign-threads/challenge.ts` 实现三颗星的 `judge`；单测 `scripts/tests/novice-assign-threads.test.mjs` 覆盖每颗星成立和不成立的情况、两种写法。
6. 新术语登记进 `docs/course/glossary.json`（每关不超过 3 个）。
7. 把 outline.json 里 `novice-assign-threads` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
