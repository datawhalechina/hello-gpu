# L-01 hello_gpu v2 教学包接口

## 目标

扩展 `notebooks/common/src/hello_gpu`，提供实验室 Notebook 需要的 v2 接口：device_card、check、bench、peak、compare、submit 和星级规则求值器。

## 背景

- 07 第 7–9 节。
- 现有包导出 HIPKernel、compile_kernel、`%%hip` 魔法、benchmark、Measurement 等（见 `__init__.py`），计时协议在 `measurement.py`。
- 旧版 Notebook 仍在用旧接口，`.github/workflows/notebook-learning.yml` 会跑检查，旧接口不能改。
- 本机可能没有 GPU：与 GPU 无关的部分必须能在没有 GPU 的机器上测试；真机验证在 R-01。

## 要做的事

1. 新增 `lab.py`、`stars.py`（可以按需要拆更多模块），在 `__init__.py` 导出新接口，旧接口保持不变。
2. `device_card()`：读取 torch 设备属性和 rocminfo（可选）；打印卡片，返回 dict，并生成 `HGCARD1.` 导入码（编码方式同通关凭证）。
3. `check` / `bench` / `peak` / `compare` 按 07 第 7 节实现；`bench` 复用 `measurement.py` 的计时协议。
4. `submit()` 按 07 第 8 节生成凭证、编码，打印通关链接和通关码，并把 JSON 存到 artifact 目录；站点地址从配置读取。
5. 星级规则求值器按 07 第 9 节实现；共享测试样例放 `docs/course/lab-rules.fixtures.json`，Python 和 TS（L-02）都跑这一份。
6. pytest 单测（`notebooks/common/tests/`）：编码解码往返、规则求值、compare 计算；没有 GPU 时，GPU 相关函数给出清楚的中文错误。
