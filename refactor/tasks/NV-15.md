# NV-15 新手村 Boss：毕业考

## 目标

按关卡模板做出「Boss 新手村毕业考：综合」，读者学完能回答：综合运用新手村的全部知识

## 背景

- 大纲条目：`docs/course/outline.json` 的 `novice-boss`（推荐 Lv.10，约 30 分钟，模拟器 L1、L2、L3、L4）。
- 学完能回答：综合运用新手村的全部知识
- 硬件落点：—
- 核心交互：修好三个坏 kernel（越界、分支发散、非合并访存）；用你的 Agent 把一个 kernel 调到三星；识破一份没同步就计时的「假加速」报告
- 本关没有 Agent 支线。
- Boss 奖励 500 XP 和「区域毕业」徽章（04 第 2、4 节）。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（新手村语气）、`03-interaction.md` 的组件登记表；读上一关的页面，保持口吻、比喻和例子连贯（新手村只用「向量加法」和「求和」两个例子）。
2. 三个坏 kernel（越界、分支发散、非合并访存）各做成一个修复挑战；Agent 调参挑战复用 A-01；「假加速」报告做成识破题，选对发「识破假加速」徽章。
3. 写 `docs/novice/boss/index.md`：frontmatter 为 `layout: stage`、`stage: novice-boss`、`newTerms`、`evidence: simulated`；按 06 第 3 节的 11 项骨架写正文；代码用 `<LangCode>` 同时给 HIP 风格和 Python 风格。
4. 本关专属的可视化放 `docs/novice/boss/scenes/`；只用登记过的组件，需要新组件时先写进完成记录的「待确认」。
5. `docs/novice/boss/challenge.ts` 实现三颗星的 `judge`；单测 `scripts/tests/novice-boss.test.mjs` 覆盖每颗星成立和不成立的情况、两种写法。
6. 新术语登记进 `docs/course/glossary.json`（每关不超过 3 个）。
7. 把 outline.json 里 `novice-boss` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
