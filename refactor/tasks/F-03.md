# F-03 截图巡检脚本

## 目标

提供 `npm run shot -- <页面路径...>`：一次截出桌面和 375px、亮色和暗色四张图，并自动检查横向滚动和控制台报错。

## 背景

- 09 第 5 节要求所有 UI 任务做截图巡检。
- 仓库还没有 Playwright。新增依赖要固定精确版本；浏览器用 `npx playwright install chromium` 安装，不进仓库。
- 站点的 base 是 `/hello-gpu/`（见 `config.mts`），脚本里的路径参数不带 base，由脚本补上。

## 要做的事

1. 新增 `playwright` 为 devDependency（精确版本）。
2. `scripts/refactor/shot.mjs`：检测本地开发服务是否在运行（端口可配置），没有就启动 `vitepress dev docs` 并在结束时关闭；对每个路径截 4 张图（1280×800、375×812，各亮色和暗色），保存到 `refactor/shots/<日期>/`。
3. 自动检查：`document.documentElement.scrollWidth > innerWidth` 视为横向滚动；收集 console error 和页面异常；有问题时退出码非 0，并打印中文汇总。
4. 支持 `--reduced-motion`（模拟减弱动效）和 `--full`（整页截图）。
5. `.gitignore` 加 `refactor/shots/`；`package.json` 加 `shot` 脚本。

## 验收标准

- [ ] `npm run shot -- /preview/tokens/` 生成 4 张截图，并在终端打印路径
- [ ] 临时做一个会横向滚动的页面，脚本能报错（验证后删掉）
- [ ] 没装浏览器时给出中文提示：运行 `npx playwright install chromium`
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /preview/tokens/`
