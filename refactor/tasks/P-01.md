# P-01 世界地图 /world/

## 目标

实现世界地图：三个区域、全部关卡（包括还没做的）、推荐等级、读者进度和「你在这」。

## 背景

- 设计稿 Map 和 Zones 画板；数据来自 `outline.json` 和 progress。

## 要做的事

1. 按设计稿布局，区域换装；关卡节点显示编号、名称、星级和状态（未开始 / 进行中 / 完成 / 已豁免 / 建设中）。
2. outline status 为 planned 的关卡显示「建设中」，不能进入；留一个接口，M-01 之后可以链接到旧版对应章节。
3. 「你在这」：最近访问的关卡或下一个推荐关卡，加脉冲光圈；减弱动效下改为静态描边。
4. Boss 节点有专门样式；副本入口的位置预留（X-01 之后启用）。
5. 手机端改成纵向路线。

## 验收标准

- [ ] 42 个关卡全部显示，编号由数据生成
- [ ] 完成一关后地图状态随之更新
- [ ] 键盘能遍历所有节点
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /world/`，逐张看过截图，把截图目录写进完成记录
