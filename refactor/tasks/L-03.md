# L-03 Notebook 生成与检查脚本

## 目标

实现 `npm run nb:build` 和 `npm run nb:check`：把 `notebooks/src/<zone>/<slug>.md` 转成按路线拆分的 `.ipynb`，并检查一致性。

## 背景

- 源文件格式见 07 第 4 节，检查项见第 11 节。不依赖 jupytext。

## 要做的事

1. `nb-build.mjs`：解析源文件；按 outline 里的 routes 生成 hip / triton 两份或一份共用版；展开 `lab:header`、`lab:submit`；metadata 写关卡 id 和路线；不保留输出；同一份源多次生成结果字节相同。
2. `nb-check.mjs`：07 第 11 节的全部检查；Python 语法检查调用 `python3 -m py_compile`，没有 Python 时跳过并提示。
3. 示例源 `notebooks/src/forge/_example.md`（不对应关卡，以下划线开头的源在关卡检查里跳过）用于演示格式和单测。
4. `package.json` 加 `nb:build`、`nb:check`，并把 `nb:check` 加入 `refactor:check`。

## 验收标准

- [ ] 示例源生成的 ipynb 符合 nbformat 4 的必需字段
- [ ] 生成结果稳定
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run nb:build`
- `npm run nb:check`
- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
