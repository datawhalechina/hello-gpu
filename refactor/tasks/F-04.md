# F-04 进度存储 v2

## 目标

实现全站共用的本地进度存储：经验值与等级、每关完成与星级、徽章、图鉴、预测记录、偏好设置、导出导入。

## 背景

- 规则：`04-gamification.md` 第 2、3、7 节。
- 试点实现：`docs/preview/sim/progress.ts`（localStorage 键 `hg-pilot-v1`）和 `docs/preview/ui/store.ts`，只覆盖单关。
- 没有后端，数据只在读者浏览器里。服务端渲染阶段不能访问 localStorage（09 第 3 节）。

## 要做的事

1. `docs/course/progress.ts`（纯 TS，node 测试可以直接导入）：数据结构带版本号 `v: 2`；接口 `completeStage`、`awardStar`、`awardBadge`、`collectTerm`、`recordPrediction`、`setPref`（写法、路线、简洁模式、减弱动效）、`levelOf(xp)`、`xpToNext(xp)`。
2. 规则：每颗星、每次完成只计一次；定级换算的经验值标注来源「定级」；豁免关卡单独标记；观摩模式完成给 100 XP，不给星。
3. `docs/course/storage.ts`：localStorage 读写（全部 try/catch）、`navigator.storage.persist()`、跨标签页同步（storage 事件）；存储不可用时退化为内存存储并给出提示。
4. 导出 / 导入：JSON 文件和「存档码」（base64url）；导入前校验版本、提示会覆盖；记录 `lastExportAt`。
5. 迁移：读到 `hg-pilot-v1` 时把试点关卡进度迁到 v2（关卡 id `novice-thread-groups`）。
6. Vue 组合式函数 `docs/course/useProgress.ts`：在 `onMounted` 之后加载，提供响应式的进度数据。
7. 单测 `scripts/tests/course-progress.test.mjs`：升级边界（0、299、300、2700 XP）、重复领取不加分、定级换算、导出再导入一致、旧版迁移。

## 验收标准

- [ ] 04 第 2 节经验值表的每一项都有对应接口，并有单测
- [ ] 导出 → 清空 → 导入后数据完全一致
- [ ] 构建时没有访问 `window` / `localStorage` 的服务端渲染报错
- [ ] 隐私模式下 localStorage 抛异常时页面不崩，并提示「本次进度不会保存」
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
