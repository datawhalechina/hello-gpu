# FG-02 2-2 第一个真 kernel（编译、运行、校验）

## 目标

按关卡模板做出「2-2 第一个真 kernel：编译、运行、校验」网页，读者学完能回答：怎样在真卡上编译、运行、校验第一个 kernel？

## 背景

- 大纲条目：`forge-first-real-kernel`（推荐 Lv.11，约 30 分钟，需要真卡）。
- 硬件落点：主机端申请显存 → 拷贝 → 启动 → 同步 → 拷回的完整流程
- 核心交互：HIP 路线写 HIP vector add；Triton 路线写 Triton vector add，并从「线程」过渡到「tile」。都用多种长度（含不能整除的）做正确性检查
- 分路线（`routes: split`）：
  - 两条路线共用：校验方法、带宽计算
  - HIP 路线：主机端完整流程：申请显存、拷贝、启动、同步
  - Triton 路线：Triton kernel 和启动网格；从线程过渡到 tile
- 本关的实验室 Notebook 由 FG-LAB-02 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（铸造城语气：工程师之间的交流，简洁）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/forge/first-real-kernel.md`。
2. 写 `docs/forge/first-real-kernel/index.md`：11 项骨架；挑战用 `LabCard`；实现部分用 `<RouteBlock route="hip">` / `<RouteBlock route="triton">`，两块的小标题和顺序一致；共用部分直接写；Mission 的星级标准从 outline 的 `lab.stars` 读取。
3. 本关可视化放 `docs/forge/first-real-kernel/scenes/`。需要真实数据的地方从档案馆读取；还没有数据时用标注「示意」的数据，并在完成记录里列出，由 R-01 替换。
4. 正文里的实测数字一律引用档案条目；暂时没有的写「[待实测]」。
5. 新术语登记进 glossary（首次出现链接概念卡）。
6. 把 outline.json 里 `forge-first-real-kernel` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
