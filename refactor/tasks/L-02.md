# L-02 LabCard 与通关凭证导入

## 目标

实现网页端的实验室入口 LabCard：打开实验室、导入成绩（链接或通关码）、按本关规则重新算星。

## 背景

- 07 第 8–10 节；03 第 6 节。

## 要做的事

1. `lab.ts`：解码 `HGPU1.`（base64url → `DecompressionStream('deflate-raw')` → JSON），校验版本、关卡 id、数字有限且为正；规则求值器和 Python 共用 fixtures。
2. `LabCard.vue`：三个入口（云平台链接 / 下载 ipynb / GitHub 查看，路线跟随偏好）；粘贴通关码；页面加载时读取 `#lab=` 自动导入，导入后清掉地址里的片段；显示读者的数字、参考数据（L-04 之前可以为空）和逐条星级判定。
3. 导入成功后发星和经验值；首次导入发「真机验证」徽章；规则里标记为「比 torch 快」的星发「打败 torch」徽章。
4. 中文错误提示：版本不对、关卡不对、数据异常。
5. 单测：解码、校验、fixtures 求值。

## 验收标准

- [ ] 用 L-01 生成的样例凭证（没有 GPU 时用伪造数据）能导入并正确算星
- [ ] 凭证里自带的结论被忽略，星级只按规则计算
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过
