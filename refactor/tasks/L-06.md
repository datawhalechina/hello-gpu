# L-06 实验环境指南

## 目标

写「实验环境指南」（`/handbook/setup/`）：在云平台和本地准备好能跑实验室的环境，并确认各平台怎样一键打开 Notebook。

## 背景

- 目标环境：本地 RX 9070 XT（gfx1201）+ ROCm；AUP Learning Cloud（Radeon 8060S，gfx1151）；AMD Radeon Cloud（以平台实际提供的卡为准）。
- 旧版附录里有安装和云平台说明（`docs/appendix/`），可以作为素材，事实要重新核对。
- 07 第 10 节：各平台是否支持 nbgitpuller 需要确认。

## 要做的事

1. 每个平台：怎么获得、怎么打开 Notebook、需要的 ROCm / PyTorch / Triton 版本；每个事实附官方链接或实测记录，查不到的写「[待实测]」。
2. 确认 nbgitpuller 或等价的一键打开方式；把结论写回 07 第 10 节，平台配置放 `docs/course/lab-platforms.json`，LabCard 据此生成链接。
3. 本地安装只写验证过的步骤，其余链接官方文档。

## 验收标准

- [ ] 每个平台都有「从零到跑通 2-1 检查脚本」的步骤
- [ ] 所有版本号和硬件参数都有出处或标「[待实测]」
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /handbook/setup/`，逐张看过截图，把截图目录写进完成记录
