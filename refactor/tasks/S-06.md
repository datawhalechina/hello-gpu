# S-06 线程机器人网格 RobotGrid

## 目标

实现线程机器人网格 + 显存格子：由模拟器事件驱动，展示谁算了哪个数，以及越界、重复和没人算。

## 背景

- 试点的 `ThreadGrid.vue`、`LaunchLab.vue` 已有一维版本的表现规则：越界红色斜纹、跳过虚线、没人算红色虚线加问号、重复琥珀色 ×N。沿用这些规则。

## 要做的事

1. 上方按 block 分组的 ThreadBot，下方显存格子；用连线或高亮表示对应关系；悬停联动。
2. 支持逐步播放事件和直接显示结果两种模式。
3. 线程很多时自动缩略（例如超过 256 个线程按 block 汇总显示）。
4. 状态不能只靠颜色区分；提供 aria 文字说明。
5. 在 `/preview/kit/` 补上演示。

## 验收标准

- [ ] 试点关卡的 5 种状态都能正确显示
- [ ] 1024 个线程时滚动和播放都流畅
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /preview/kit/`，逐张看过截图，把截图目录写进完成记录
