# X-08 外部题索引与原创题解

## 目标

建立外部练习题索引（LeetGPU 等），按区域推荐，并写 2–4 篇原创题解作为示范。

## 背景

- LeetGPU 题库为 CC BY-NC-ND 4.0：只能链接，不能翻译或改编题面。题解里的思路和代码是我们原创的，但不能复述题面。
- GPU MODE reference-kernels 使用自定义许可证，只链接。GPU-Puzzles 为 MIT，可以改编，要署名。

## 要做的事

1. `external-problems.json`：题名、来源、链接、许可证、推荐区域、关联关卡。
2. 索引页用 `ExternalProblem` 卡片展示，按区域分组。
3. 写 2–4 篇原创题解（铸造城难度为主）：思路、关键代码、和本书哪一关的知识对应；不复述题面。题解代码的真机验证在 R-05。

## 验收标准

- [ ] 索引和题解里没有任何外部题面文字
- [ ] 每道外部题标明来源和许可证
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /dungeon/external/`，逐张看过截图，把截图目录写进完成记录
