# TR-09 3-9 Attention（在线 Softmax 与分块）

## 目标

按关卡模板做出「3-9 Attention：在线 Softmax 与分块」网页，读者学完能回答：在线 Softmax 和分块怎样省掉中间矩阵？

## 背景

- 大纲条目：`trial-attention`（推荐 Lv.28，约 90 分钟，需要真卡）。
- 硬件落点：把多个阶段融合在一个 kernel 里，中间结果留在寄存器和 LDS
- 核心交互：手动推进 online softmax 的状态；实测和朴素实现、库实现对比
- 分路线（`routes: split`）：
  - 两条路线共用：题目、硬件讲解、实测
  - HIP 路线：HIP 实现
  - Triton 路线：Triton 实现
- 本关的实验室 Notebook 由 TR-LAB-09 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（试炼场语气：精确，引用一手资料）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/trial/attention.md`。
2. online softmax 状态推进器：读者手动推进，每步显示 m、l 和输出累加值。
3. 写 `docs/trial/attention/index.md`：11 项骨架；挑战用 `LabCard`；实现部分用 `<RouteBlock route="hip">` / `<RouteBlock route="triton">`，两块的小标题和顺序一致；共用部分直接写；Mission 的星级标准从 outline 的 `lab.stars` 读取。
4. 本关可视化放 `docs/trial/attention/scenes/`。需要真实数据的地方从档案馆读取；还没有数据时用标注「示意」的数据，并在完成记录里列出，由 R-08 替换。
