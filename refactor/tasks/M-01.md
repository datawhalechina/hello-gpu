# M-01 旧版入口与章节映射

## 目标

旧版章节保留原有 URL，新增旧版目录页 `/v1/`，并建立旧章节到新关卡的映射：旧页面提示新版对应关卡，地图上「建设中」的关卡链接旧版章节。

## 背景

- 旧版章节在 `docs/part*`、`docs/appendix`，URL 不变，避免外部链接失效。旧版 Notebook 也留在 `notebooks/part*/` 不动。

## 要做的事

1. `docs/course/v1-map.json`：旧章节路径 → 新关卡 id 列表（多对多）。
2. `/v1/` 目录页：列出旧版全部章节，说明「这是旧版教程，内容仍然可用」。
3. 旧版页面顶部加一条提示：新版对应的关卡（有映射且关卡已上线时显示）。
4. 世界地图上 status 为 planned 的关卡，有映射时显示「先看旧版」链接。

## 验收标准

- [ ] 旧版所有章节的 URL 仍然可以访问
- [ ] 映射覆盖旧版全部章节
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
