# S-03 模拟器 L3：访存模型

## 目标

实现访存模型：根据事件流算出一次访存要搬几「车」（cache line），以及 LDS bank 冲突（为试炼场预留）。

## 背景

- 08 第 2、5 节。L3 的参数都是示意值。

## 要做的事

1. `analyzeMemory(events, { lineBytes, elemBytes })`：每次访存的事务数、理想事务数、效率和汇总。
2. `analyzeLdsBanks(events, { banks, bankBytes })`：每次 LDS 访问的冲突度（新手村不展示，试炼场 3-5 的可视化可以用）。
3. `params.ts` 集中放示意参数，每项注明「示意」和取值理由。
4. 单测：连续访问、步长 2 / 4 / 32、随机、广播、LDS 冲突的手算例。
