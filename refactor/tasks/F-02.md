# F-02 新版路由、布局注册与站点配置

## 目标

为新版页面准备好路由、布局注册、路径别名和 noindex 规则。之后的任务可以直接在最终路径下写页面，旧版导航不受影响。

## 背景

- URL 规划见 `refactor/PLAN.md` 第 4 节：`/world/` `/preface/` `/placement/` `/me/` `/handbook/` `/lab/` `/dungeon/` `/novice/` `/forge/` `/trial/`。
- 旧版导航和侧边栏由 `docs/.vitepress/outline.mjs` 生成；`docs:sync-outline`、`docs:check-chapter-ui` 两个脚本会扫描章节，要确认它们忽略新目录。
- `config.mts` 已有 `srcExclude: ['**/AGENTS.md']`。

## 要做的事

1. 在主题里注册两个新布局：frontmatter `layout: hg`（通用页面，F-06 实现）和 `layout: stage`（关卡，F-10 实现），先用占位组件。
2. 配置 Vite 别名：`@course` → `docs/course`，`@kit` → `docs/components/kit`，`@sim` → `docs/sim`。
3. 新版路径默认 noindex：在 `transformHead` 里按路径前缀加 `<meta name="robots" content="noindex">`，由 `config.mts` 里的常量 `V2_PUBLIC = false` 控制，M-02 上线时改为 true。`/preview/` 下的页面始终 noindex。
4. 为上面每个路径建占位 `index.md`（标题 + 「建设中」），使用 `layout: hg`。
5. 新建 `docs/components/kit/index.ts` 作为全局注册入口（先为空），在主题 `enhanceApp` 里调用。
6. 确认旧版侧边栏、导航、`docs:check-chapter-ui`、`docs:sync-outline` 不受影响。

## 验收标准

- [ ] `/world/`、`/novice/` 等占位页能打开，页面 head 里有 noindex
- [ ] 旧版侧边栏和导航里没有出现新页面
- [ ] 在页面里用 `@course/outline.json` 别名导入能工作（验证后删掉验证代码）
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run docs:dev` 后打开 `/world/` 和旧版任意一章，在浏览器里检查桌面和 375px 宽度、亮色和暗色
