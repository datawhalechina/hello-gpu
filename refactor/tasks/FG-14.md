# FG-14 铸造城 Boss：毕业考

## 目标

按关卡模板做出「铸造城 Boss：综合」网页，读者学完能回答：综合运用铸造城的全部知识

## 背景

- 大纲条目：`forge-boss`（推荐 Lv.20，约 90 分钟，需要真卡）。
- 硬件落点：—
- 核心交互：选一个 torch 算子（Softmax、RMSNorm 或 bias + GELU），用自己的路线手写版本打败 torch；再让 Agent 在同一任务上复现，并提交可复核的报告
- 分路线（`routes: split`）：
  - 两条路线共用：任务和评分标准
  - HIP 路线：用 HIP 完成
  - Triton 路线：用 Triton 完成
- 本关的实验室 Notebook 由 FG-LAB-14 编写；网页的「探索」各段和 Notebook 的「动手」各段一一对应。
- 本关没有 Agent 支线。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（铸造城语气：工程师之间的交流，简洁）、`03-interaction.md`；读上一关的页面和本关 Notebook 源 `notebooks/src/forge/boss.md`。
2. 写 `docs/forge/boss/index.md`：11 项骨架；挑战用 `LabCard`；实现部分用 `<RouteBlock route="hip">` / `<RouteBlock route="triton">`，两块的小标题和顺序一致；共用部分直接写；Mission 的星级标准从 outline 的 `lab.stars` 读取。
3. 本关可视化放 `docs/forge/boss/scenes/`。需要真实数据的地方从档案馆读取；还没有数据时用标注「示意」的数据，并在完成记录里列出，由 R-05 替换。
4. 正文里的实测数字一律引用档案条目；暂时没有的写「[待实测]」。
5. 新术语登记进 glossary（首次出现链接概念卡）。
6. 把 outline.json 里 `forge-boss` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
