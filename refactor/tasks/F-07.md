# F-07 术语表、徽章定义与图鉴接口

## 目标

建立全站统一的术语表和徽章定义，以及「收入图鉴」「发放徽章」两个接口。

## 背景

- 04 第 4、5 节；05 第 3、4 节（译名规则、工坊城比喻表）。
- 试点关卡用到的术语：block、grid、全局下标。新手村每关新术语不超过 3 个。

## 要做的事

1. `docs/course/glossary.json`：结构 `{ "<key>": { term, en, zone, short, analogy, analogyLimit, links } }`。先录入新手村 14 关会用到的术语（按 `refactor/OUTLINE.md` 推断，约 30 个），每条一句大白话定义；比喻和比喻边界只用 05 第 4 节的体系。
2. `docs/course/badges.json`：04 第 4 节的首批徽章，字段 `{ id, name, desc, icon, condition }`；判定函数集中在 `docs/course/badges.ts`。
3. 在 `progress.ts` 接上 `collectTerm(key)` 和 `awardBadge(id)`。
4. `scripts/refactor/course-data-check.mjs`：校验 glossary 和 badges 的结构、键唯一、必填字段；加入 `refactor:check`。
5. 单测：术语键唯一、每条有定义、徽章条件判定。

## 验收标准

- [ ] 术语表覆盖新手村 14 关的新术语，没有同一概念的两个名字
- [ ] 每条术语有中文名、英文名、一句话定义；有比喻的写明比喻边界
- [ ] 徽章定义和 04 第 4 节一致
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
