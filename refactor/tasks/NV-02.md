# NV-02 1-2 走进工坊城（GPU 全景图）

## 目标

按关卡模板做出「1-2 走进工坊城：GPU 全景图」，读者学完能回答：GPU 由哪些部分组成？一个任务从 CPU 交给 GPU，经过了哪些地方？

## 背景

- 大纲条目：`docs/course/outline.json` 的 `novice-gpu-panorama`（推荐 Lv.1，约 15 分钟，模拟器 不用）。
- 学完能回答：GPU 由哪些部分组成？一个任务从 CPU 交给 GPU，经过了哪些地方？
- 硬件落点：芯片 → 计算单元 CU（RDNA 里两个 CU 组成一个 WGP）→ SIMD → lane；寄存器、LDS、缓存、显存；CPU 与 GPU 之间的数据拷贝
- 核心交互：可以逐层放大的芯片全景图；「一个任务的旅程」动画：拷进显存 → 启动 → 计算 → 拷回
- 本关没有 Agent 支线。
- 全景图会被 L-07 复用：读者导入「我的 GPU 卡片」后，CU 数、wave 大小、显存容量换成真机参数。
- 硬件参数只能来自官方资料，集中写进 `docs/course/hardware.json`（09 第 4 节），每条附来源链接。

## 要做的事

1. 读大纲条目、`06-stage-template.md`、`05-writing.md`（新手村语气）、`03-interaction.md` 的组件登记表；读上一关的页面，保持口吻、比喻和例子连贯（新手村只用「向量加法」和「求和」两个例子）。
2. 做一个可以逐层放大的芯片全景图组件（芯片 → WGP / CU → SIMD → lane，以及寄存器、LDS、缓存、显存），参数通过 props 传入，默认值来自 `hardware.json` 里的 RX 9070 XT。
3. 做「一个任务的旅程」动画：拷进显存 → 启动 → 计算 → 拷回。
4. 建立 `docs/course/hardware.json`，写入本关用到的 RX 9070 XT 参数，每条附官方来源；查不到的写「[待实测]」。
5. 写 `docs/novice/gpu-panorama/index.md`：frontmatter 为 `layout: stage`、`stage: novice-gpu-panorama`、`newTerms`、`evidence: simulated`；按 06 第 3 节的 11 项骨架写正文；代码用 `<LangCode>` 同时给 HIP 风格和 Python 风格。
6. 本关专属的可视化放 `docs/novice/gpu-panorama/scenes/`；只用登记过的组件，需要新组件时先写进完成记录的「待确认」。
7. 挑战用登记过的交互组件实现三颗星的判定；判定逻辑写成纯函数放 `docs/novice/gpu-panorama/challenge.ts`，单测 `scripts/tests/novice-gpu-panorama.test.mjs`。
8. 新术语登记进 `docs/course/glossary.json`（每关不超过 3 个）。
9. 把 outline.json 里 `novice-gpu-panorama` 的 `status` 改成 `draft`，运行 `npm run outline:md`。
