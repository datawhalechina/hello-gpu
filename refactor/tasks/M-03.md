# M-03 全站巡检

## 目标

对新版全站做一次巡检：内部链接、截图、可访问性、性能预算；能当场修的修掉，修不了的拆成新任务。

## 背景

- 09 第 5、6 节。

## 要做的事

1. `scripts/refactor/link-check.mjs`：检查新版页面的内部链接和锚点，加入 `refactor:check`。
2. 对全部新版页面跑截图巡检，逐页看。
3. 可访问性抽查：键盘遍历、焦点、对比度、减弱动效（可以用 axe-core，新增依赖按规范处理）。
4. 性能：检查每个页面的首屏 JS 和图片体积是否超预算。
5. 问题清单写进完成记录；超出本任务范围的拆成新任务（编号 M-03a、M-03b……）。

## 验收标准

- [ ] 没有失效的内部链接
- [ ] 每个新版页面都通过截图巡检
- [ ] 性能预算全部满足，或在完成记录里列出例外和原因
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- <全部新版页面>`
