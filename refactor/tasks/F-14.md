# F-14 关卡规范自动检查

## 目标

让 `npm run refactor:check` 自动检查新版关卡页面的格式和写作规范，减少人工审查。

## 背景

- 06 第 2、3、8 节；05 第 5 节（禁用词）；03 第 3 节（组件登记表）。

## 要做的事

1. 扫描 `docs/{novice,forge,trial}/*/index.md`，只检查 outline 里 status 为 draft 或 ready 的关卡。
2. frontmatter：`layout: stage`；`stage` 存在于 outline 且和目录一致；`newTerms` 都在 glossary 里，新手村不超过 3 个；`evidence` 取值合法。
3. 骨架：Mission、Predict、ConceptCard、Checkpoint、EvidenceCard 都出现且顺序正确；`gpu: true` 的关卡有 LabCard。
4. 只用登记过的组件：登记表放 `docs/course/components.json`（内容来自 03 第 3 节）。
5. 禁用词：列表放 `docs/course/banned-words.json`（来自 05 第 5 节）。
6. 新手村单个代码块不超过 10 行。
7. 中文报错，带文件和行号；加入 `refactor:check`；单测用几份小样例覆盖每条规则。

## 验收标准

- [ ] 每条规则都有通过和不通过的单测样例
- [ ] 当前仓库检查通过
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
