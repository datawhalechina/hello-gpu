# R-01 真机验证与档案：铸造城 2-1 至 2-4

## 目标

在装有 AMD GPU 和 ROCm 的机器上跑通 2-1 开工准备、2-2 第一个真 kernel、2-3 测得准、2-4 性能的天花板 的实验室 Notebook（每条路线都跑），修正问题，把参考运行记录存进档案馆，替换网页里的「[待实测]」和示意数据。

## 背景

- 07 第 6、12 节：每本 Notebook 要能「Restart Kernel and Run All」从头跑通；RX 9070 XT 上不超过 10 分钟。
- 星级阈值要让认真完成的读者能拿到，又不能让朴素实现直接拿三星。

## 要做的事

1. 确认环境：`rocminfo`、`hg.device_card()`；在完成记录里写下设备和软件版本。
2. 顺带完成 L-01 的真机验证：`device_card`、`bench`、`peak` 在真卡上的结果合理；把 `hg.device_card()` 的导入码导入网页，确认 L-07 的流程。
3. 每本 Notebook「Restart & Run All」，记录耗时；出错就修改源文件，重新 `npm run nb:build`。
4. 运行交成绩单元，用通关链接打开本地站点（`npm run docs:dev`），确认导入和星级判定正确；调整 `lab.stars` 阈值时在完成记录里写明理由。
5. 把参考实现的运行记录存成档案条目（L-04 格式），确认观摩模式能回放。
6. 替换对应网页里的「[待实测]」和示意数据，EvidenceCard 指向档案条目。

## 验收标准

- [ ] 每本 Notebook 在真卡上从头跑通，耗时写进完成记录
- [ ] 通关链接导入后星级判定正确
- [ ] 每关每条路线至少有一条档案条目，观摩模式可以回放
- [ ] 对应网页里没有剩余的「[待实测]」（确实测不了的在完成记录里说明）
- [ ] L-01、L-07 的真机部分已验证
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- 在有 AMD GPU 的机器上运行 Notebook
- `npm run nb:check`
- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
