# S-05 代码沙盒 Sandbox

## 目标

实现代码沙盒：HIP 风格和 Python 风格编辑、填空模式与完整模式、运行 / 单步 / 重置、错误定位到行；手机上退化为填空。

## 背景

- 03 第 3、4、7 节；09 第 3 节预计使用 CodeMirror 6，要按需加载。

## 要做的事

1. CodeMirror 6 通过动态 import 按需加载，首屏不加载；两种写法的语法高亮。
2. 填空模式：代码大部分只读，只开放标记的空；完整模式：整段可编辑。
3. 运行通过 `docs/sim/client.ts`；把结果和事件交给父组件（RobotGrid、WaveView 等）显示。
4. 错误展示为「现象 + 原因 + 怎么改」，定位到行；解析器原文放进折叠块。
5. 接入 F-12：草稿自动保存、重置回初始代码、失败次数驱动提示阶梯。
6. 写法跟随 F-11 的偏好；两种写法各有初始代码和草稿。
7. 375px：填空模式改用输入框或选项，不加载编辑器。
8. 在完成记录里写明新增依赖的体积，并检查首屏 JS 没超预算。

## 验收标准

- [ ] 两种写法都能完成试点关卡的挑战，结果相同
- [ ] 首屏 JS 里不包含 CodeMirror（检查构建产物）
- [ ] 手机宽度下能完成填空挑战
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
- `npm run shot -- /preview/kit/`，逐张看过截图，把截图目录写进完成记录
