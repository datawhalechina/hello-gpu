# Q-01 定级测试题库

## 目标

设计定级测试题库和计分规则：判断读者应该从哪个区域、哪一关开始，可以豁免哪些关卡。

## 背景

- 04 第 2 节：定级给出的等级换算成经验值，豁免关卡不给星。

## 要做的事

1. 三组题（新手村、铸造城、试炼场），每组 6–8 题；每题关联 1–3 个关卡 id，答对表示这些关卡可以豁免。
2. 题型：选择、估值、读代码判断结果。考理解，不考记忆；没学过的人不能靠猜答对。每个选项都有解释。
3. 计分（纯函数 `placement.ts`）：逐组作答，某组正确率低于阈值就停下，推荐从这一组开始；给出推荐等级。
4. 单测覆盖计分和推荐逻辑。

## 验收标准

- [ ] 每个区域的每个 arc 至少有一道题
- [ ] 每道题的每个选项都有解释
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过

## 验证方式

- `npm run refactor:check`
- `npm test`
- `npm run docs:build`
