# NV-11 1-11 测一测有多快（计时与带宽）

## 目标

按关卡模板做出「1-11 测一测有多快：计时与带宽」，读者学完能回答：怎么知道真的变快了？带宽怎么算？

## 背景

- 大纲条目：`docs/course/outline.json` 的 `novice-timing`（推荐 Lv.7，约 15 分钟，模拟器 L4）。
- 学完能回答：怎么知道真的变快了？带宽怎么算？
- 硬件落点：kernel 启动是异步的，CPU 不等 GPU；有效带宽 = 搬运字节数 ÷ 时间
- 核心交互：计时陷阱：三份测量结果哪份可信（未同步、未预热）；算出 vector add 的带宽
- 本关有 Agent 支线（06 第 3 节第 7 项）。A-01 之前用文字 + 一个小交互说明「如果让 Agent 来做这一步，它会观察什么、尝试什么」；A-01 完成后可以换成 AgentConsole 回放。
