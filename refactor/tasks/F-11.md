# F-11 LangCode、RouteBlock 与偏好切换

## 目标

新手村按写法偏好显示 HIP 风格或 Python 风格代码，铸造城和试炼场按路线显示 HIP 或 Triton 内容；两个偏好分开保存，在状态栏切换。

## 背景

- 03 第 5 节；06 第 5 节。试点有 `LangSwitch.vue` 和 `LangCode.vue`。

## 要做的事

1. LangCode：两种写法的代码块，按偏好显示一个。
2. RouteBlock：`route="hip|triton"`，只显示当前路线；块顶部有路线标签和「切换路线」。
3. 服务端渲染输出两种内容，客户端按偏好用 CSS 隐藏另一种，避免水合不一致和布局跳动。
4. StageLayout 状态栏：新手村显示写法切换；铸造城、试炼场且关卡 `routes: split` 时显示路线切换；`shared` 关卡不显示。
5. 偏好通过 `setPref` 存进 progress；在 `/preview/kit/` 补上演示。

## 验收标准

- [ ] 切换后全页同步，刷新后保持
- [ ] 新手村页面不出现路线切换，shared 关卡不出现路线切换
- [ ] 控制台没有水合不一致的警告
- [ ] 截图巡检通过（桌面 / 375px × 亮色 / 暗色），没有横向滚动和控制台报错
- [ ] `npm run refactor:check`、`npm test`、`npm run docs:build` 全部通过
