# S-04 模拟器 L4：示意计时与占用率

## 目标

实现示意计时与占用率模型，回答「哪种写法更好」和「等待怎样被别的 wave 藏住」。

## 背景

- 08 第 2、5、7 节。所有数值都标注「模拟」。

## 要做的事

1. `estimateTime(events, params)`：示意周期数，拆成计算 / 访存 / 同步三部分。
2. `occupancy(params)`：给定每线程寄存器数、每 block 的 LDS 用量和 block 大小，算出每个 SIMD 能驻留的 wave 数（规则形式和真实硬件一致，数值为示意）。
3. 延迟隐藏演示需要的时间线：多个 wave 交替执行的事件序列。
4. 单测：至少 5 个手算例；单调性检查（访存更合并 → 示意时间不增加；占用率更高 → 被隐藏的比例不降低）。
