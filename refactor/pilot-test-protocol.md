# 试点关卡 1-3 试玩方案

这份方案用来回答一个问题：新版的交互关卡，是否比现有教程更容易学、学得更牢，也更让人想继续学？

## 1. 对照设计

| 组别 | 学习材料 | 地址 |
| --- | --- | --- |
| A 组（现有教程） | 第 2 章 2.2.1「线程块与网格」，以及 2.3.1–2.3.3「线程编号、数组下标、边界检查」 | `/part0-intro/chapter2/` |
| B 组（新版关卡） | 1-3 线程分组 | `/preview/novice/thread-groups` |

- 人数：6–8 位零基础目标读者，A、B 各一半。尽量让两组的背景接近（比如都只会一点 Python）。
- 本地预览：`npm run docs:build && npx vitepress preview docs`，然后打开 `http://localhost:4173/hello-gpu/preview/novice/thread-groups`。也可以把分支部署到一个临时地址。
- 每位 B 组读者开始前，在页面底部「试玩研究」里点「清空本关进度」。

## 2. 流程（每人约 35 分钟）

1. 开场 2 分钟：说明「我们在测试教程，不是在测试你」，请对方边做边说出想法，征得录屏同意。
2. 学习，不限时：记录用时。观察者只记录，不提示；对方卡住超过 3 分钟可以问一句「你现在在想什么？」。
3. 后测 10 分钟：做第 3 节的 5 道题，可以用纸笔，不能翻看教程。
4. 问卷 3 分钟：第 4 节。
5. B 组：导出试玩日志（页面底部「导出试玩日志」），把 JSON 文件发回。
6. 第二天：发第 5 节的追问题，请对方不看教程作答。

## 3. 后测题（两组相同，都不同于教程里的例子）

1. 每组 16 个线程，要处理 100 个数，至少要几组？
   - 答案：7 组（6 组只有 96 个线程）。
2. 接上题，如果不加边界检查，有几个线程会写到数组外面？
   - 答案：12 个（7 × 16 = 112，112 − 100 = 12）。
3. 每组 32 个线程，`blockIdx.x = 2`、`threadIdx.x = 7` 的线程处理哪个下标？
   - 答案：71（2 × 32 + 7）。
4. 有人把下标写成 `i = threadIdx.x`，用 4 组、每组 8 个线程处理 32 个数。结果会怎样？
   - 答案：只有 c[0]～c[7] 被计算，而且每个被算了 4 次；c[8]～c[31] 没人算。说出「前面重复、后面没人算」即得分。
5. 用自己的话解释：为什么几乎每个 kernel 都要写 `if (i < n)`？
   - 评分（0–2 分）：提到「派出的线程数通常多于数据个数」得 1 分；提到「多出来的线程会写到数组外面 / GPU 不会自动检查」得 1 分。

满分 6 分（前 4 题各 1 分，第 5 题 2 分）。

## 4. 问卷

| 问题 | 形式 |

| 这一节难不难？ | 1（太简单）– 5（太难） |

| 哪里最让你困惑？ | 开放题 |
| 哪里最喜欢，或者让你「原来如此」？ | 开放题 |

## 5. 第二天追问

> 每组 64 个线程，要处理 1000 个数。写出：（1）组数的计算式和结果；（2）每个线程的下标公式；（3）还需要加什么？

答案：（1）(1000 + 63) / 64 = 16 组；（2）`i = blockIdx.x * blockDim.x + threadIdx.x`；（3）边界检查 `if (i < n)`。每小问 1 分。

## 6. 判断标准

样本很小，以下标准用来发现明显差距，不做统计检验：

| 指标 | 达标线 |
| --- | --- |
| 后测得分 | B 组平均分不低于 A 组 |
| 第二天追问 | B 组平均分高于 A 组 |
| 学习用时 | B 组平均不超过 15 分钟 |
| 想继续学 | B 组平均 ≥ 4 分 |
| 先猜正确率（来自日志 `predict.lock`） | 每道题在 40%–70% 之间；全对说明太简单，全错说明铺垫不够 |
| 卡关 | 没有哪个实验让超过一半的人在不看提示的情况下卡住（日志 `lab.run` 的 `failedRuns`、`lab.hint`） |

达标：进入 P1，铺开前言和 1-1、1-2。不达标：先改 `docs/preview/AGENTS.md` 里的规范，再改关卡。

## 8. 日志里的事件

| 事件 | 含义 |
| --- | --- |
| `stage.open` / `stage.leave` / `stage.hidden` | 打开、离开、切到后台（含停留毫秒数） |
| `predict.lock` | 锁定预测：哪道题、选了哪个、对不对 |
| `lab.run` | 点运行：规则、写法、参数、是否成功、累计失败次数 |
| `lab.knob` / `lab.guard` | 调参数、开关边界检查 |
| `lab.hint` / `lab.answer` | 出现提示、查看答案 |
| `lab.success` | 某个实验第一次达成目标 |
| `lab.gate.skip` | 跳过预测直接看实验 |
| `star` / `stage.complete` | 拿到星、完成关卡 |
| `checkpoint.answer` | 检查点作答 |
| `codex.learn` | 新术语进入图鉴 |
| `lang.change` | 切换 HIP / Python 写法 |
