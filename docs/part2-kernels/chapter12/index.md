## 12.1 从 LayerNorm 到 RMSNorm

从公式和数据流解释 RMSNorm 保留了什么、移除了什么，以及它为什么适合作为综合逐元素、归约与融合的结业题。

## 12.2 固定数学语义、误差和目标 Shape

先锁定 dtype、归约轴、epsilon、参考实现、误差标准和目标输入，再讨论任何实现或优化。

## 12.3 HIP：从分步 Baseline 到融合实现

先建立可逐段检查的分步正确版本，再逐次验证归约、数据驻留与融合边界；每一轮只改变一个主要机制。

## 12.4 Triton：一行一个 Program

用一个 program 覆盖一行，明确 offsets、mask、归约范围与写回位置，再受控实验 block size、num warps 和长行边界。

## 12.5 正确性、Benchmark 与 Profiling

用统一的正确性矩阵、kernel-only 计时口径和可追溯 profiling 字段比较各版本，不用源码表象替代证据。

## 12.6 独立优化记录与失败回退

保留每轮假设、单变量改动、正确性结果、性能结果、负结果和回退点，形成另一位读者可以复跑的报告。

## 12.7 从 RMSNorm 迁移到新题目

把逐元素、归约和融合模式迁移到新的算子规格；迁移的是分析顺序和实验契约，不是背诵最终代码。

## 12.8 拓展练习：LeetGPU 与其他平台

可以把同一闭环用于平台题目，但需要重新核对接口、支持语言、运行环境、隐藏 shape 与评分口径。平台成绩不能替代本书实验机上的本地证据。
