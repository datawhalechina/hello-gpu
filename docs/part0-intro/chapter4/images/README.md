# 第 4 章教学图

本目录中的三张 SVG 是本项目原创、可直接编辑的概念示意图；不包含性能实测数据，也不表示设备的物理布局或精确时间比例。

| 文件 | 画布 | 图义 |
| --- | --- | --- |
| `vector-add-data-path.svg` | 1200 × 780 | 本章最小 HIP 程序的数据往返；用实线表示数据移动，虚线表示 CPU 的分配和启动控制。实际程序可以复用 GPU 上的数据。 |
| `thread-index.svg` | 1200 × 710 | n = 1,048,576、每 block 256 线程时，block 2 的 thread 5 对应 idx = 517。block 的分组不表示同时执行。 |
| `event-timing.svg` | 1200 × 840 | 预热与结果校验在样本之外；GPU 的起点、终点事件围住加法，CPU 等待终点完成后才读取 elapsed_time。 |

视觉约定：暖白底、深灰文字；输入 a 为蓝色，输入 b 为橙色，输出 c 为绿色。图内同时标注名称，颜色不是唯一信息来源。每张 SVG 提供 title / desc 文本说明，并使用字体回退列表支持简体中文。

旧 PNG 为前一版插画，保留文件不代表正文仍在使用。
